# QQ邮箱投递

发件人与收件人在本机`config/mail.json`中配置，该文件不入Git仓库。首次克隆后，复制`config/mail.example.json`为`config/mail.json`，填写自己的QQ发件地址及收件地址。

SMTP是程序把邮件交给邮箱服务器的协议。本项目连接`smtp.qq.com:465`，使用TLS加密和QQ客户端授权码。

## 首次配置

在项目根目录运行：

```sh
python3 pipeline/mail_setup.py --edition 2026-11-21
```

打开终端输出的本机URL。页面先显示发件人、收件人、日期及正文预览。

1. 在QQ邮箱登录配置的发件账号，进入「设置 → 账号与安全 → 安全设置」，开启IMAP/SMTP服务并生成授权码。旧版入口可能为「设置 → 账户」。QQ要求的扫码或短信验证由账号本人完成。
2. 将客户端授权码粘贴到本机设置页，点击「保存并验证」。请勿粘贴QQ登录密码或将授权码发到聊天。程序先登录QQ验证，再保存在Mac钥匙串的项目专用条目中；不写入配置文件、日志或进程参数。Mac弹出钥匙串提示时，按提示完成操作。
3. 查看预览后，点击「发送这份报纸」。该操作才会向指定163地址发信。

邮件正文是天气与四栏导读，附件是完整六版HTML。附件下载后用浏览器打开，保留翻页、原画与来源账单。当前没有PDF附件。

## 后续使用

已有当天报纸时，先生成预览：

```sh
python3 pipeline/mail_delivery.py --edition 2026-11-21
```

这个命令不发信。输出保存在`data/editions/2026-11-21/mail/`，包含正文预览、`.eml`及附件校验信息。

单独验证账号（不发送邮件）：

```sh
python3 pipeline/mail_delivery.py --edition 2026-11-21 --check-auth
```

明确发送及查看状态：

```sh
python3 pipeline/mail_delivery.py --edition 2026-11-21 --send
python3 pipeline/mail_delivery.py --edition 2026-11-21 --status
```

同一期、同一组发件人和收件人只提交一次；并行发送会被锁住。状态`accepted`表示QQ服务器已接受邮件，实际到达请查看163收件箱或垃圾邮件。发送中断导致结果不明时，状态为`unknown`，程序会阻止重试；先检查收件箱，再人工处理投递记录，避免重复。

本地投递记录在`.local/mail/receipts/`。授权码存于Mac钥匙串，服务名`cyber-newspaper.smtp.qq.com`，账号为配置的QQ地址。

这一步只完成邮件投递。尚未添加定时任务，也没有自动选题、撰稿的每日生产调度。
